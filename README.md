# 🚀 EC Project - Workflow & Collaboration System

A full-stack task management system with Kanban board, analytics dashboard, and approval workflow.

---

## 🛠 Tech Stack

### Frontend:
- React JS
- Tailwind CSS
- Recharts
- React Router

### Backend:
- FastAPI
- SQLAlchemy
- SQLite / PostgreSQL

---

## 📊 Features

✔ Task Management (CRUD)  
✔ Kanban Board (Todo / In Progress / Done)  
✔ Dashboard Analytics (Charts)  
✔ Approval System  
✔ Modern UI (Dark Theme)
